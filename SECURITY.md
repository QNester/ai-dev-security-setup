# Security Policy

## Как сообщить об уязвимости

Пожалуйста, **не создавайте публичный issue** для уязвимостей.

Используйте GitHub Security Advisories:

<https://github.com/QNester/ai-dev-security-setup/security/advisories/new>

Если этот способ недоступен, свяжитесь с владельцем репозитория напрямую
через GitHub и попросите приватный канал.

В отчёте укажите:

- версию или commit;
- версию Ubuntu/Debian и ядра;
- какие CLI и параметры установки использовались;
- шаги воспроизведения;
- ожидаемое и фактическое поведение;
- оценку влияния.

Не прикладывайте реальные API-ключи, `LITELLM_MASTER_KEY`, приватные SSH-ключи
и другие секреты. Замените их на плейсхолдеры.

## Область действия

Проект включает:

- `sandboxctl` — Go-реализация изоляции и управления жизненным циклом;
- `setup-ai-sandbox.sh` — reference-установщик системной интеграции;
- `start-litellm.sh` — запуск локального LiteLLM;
- лаунчеры-симлинки, правила nftables/SBPL, AppArmor-профиль и unit-файлы
  systemd/launchd.

Актуальные ограничения Go-реализации и модель угроз описаны в
[docs/security.md](docs/security.md).

В область действия входят ошибки, которые приводят к:

- выходу из Bubblewrap-песочницы;
- доступу `ai-dev` к файлам владельца вне `SHARED_DIR`;
- повышению привилегий до root;
- обходу сетевых ограничений;
- утечке секретов из песочницы;
- выполнению кода от root через установщик.

Не входят в область действия:

- уязвимости самих Claude Code, Kimi Code, Pi, OpenCode и LiteLLM —
  сообщайте их соответствующим проектам;
- уязвимости провайдеров моделей;
- известные ограничения, перечисленные в разделе
  [«Безопасность»](README.md#security), включая доверие к содержимому
  `SHARED_DIR`, отсутствие изоляции уровня VM и best-effort LAN-фильтрацию.

## Поддерживаемые версии

Поддерживается текущая ветка `main`. Исправления для старых коммитов не
выпускаются; обновитесь до последней версии.

## Раскрытие

После подтверждения проблемы будет подготовлено исправление и, если это
уместно, публичное уведомление. Пожалуйста, дайте разумное время на выпуск
исправления до публичного раскрытия.
